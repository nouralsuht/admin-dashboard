# Vita Admin

Frontend only: HTML, CSS, JavaScript and Bootstrap 5.
Open index.html or views/admin/dashboard.html.

- views/admin/: six administration pages.
- assets/css/admin.css: responsive styling and pastel table rows.
- assets/js/admin-data.js: two related samples per table.
- assets/js/admin.js: navigation, search, filters, pagination and demo editing.
- models/ and controllers/: reserved for future PHP integration.

Changes are saved in browser storage. Reset demo restores samples.
Choose 1 in Rows to try both pages. Prices are in JOD.
Original template pages have been removed; bundled vendor source assets remain.
